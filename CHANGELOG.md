# Changelog

All notable changes to **verso-mcp** are recorded here.

From the next release onward this file is generated by
[commitizen](https://commitizen-tools.github.io/commitizen/) from
[Conventional Commit](https://www.conventionalcommits.org/) messages — run
`cz bump` to cut a release and add its entry. The entries below cover releases
made before that workflow was adopted.

## 0.3.1 (2026-05-16)

### Fix

- Report a clear error when a configured URL is not a Verso site, instead of
  letting a `JSONDecodeError` escape uncaught.
- Keep every indexed entry URL within its owning site; skip off-site addresses.
- Stop misparsing a bare site URL that contains `=`.

## 0.3.0 (2026-05-16)

### Feat

- Generalize from a single-site Lean Reference server into a multi-site Verso
  documentation server: a `VERSO_MCP_SITES` registry, per-site indexing and
  caching, dynamically derived entry kinds, an optional `site` parameter, and a
  new `list_sites` tool. Renamed from `lean-reference` to `verso`, and packaged
  for PyPI.

## 0.2.0 (2026-05-16)

### Feat

- First release: an async Model Context Protocol server for the Lean Language
  Reference, built on Verso's published `xref.json` index. Provides `search`,
  `fetch_page`, and `list_kinds`, with SSRF-scoped fetching, a token-bucket rate
  limiter, disk caching with conditional revalidation, and bounded responses.
